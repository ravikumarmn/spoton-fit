# Security

SpotOn handles health-related personal data, so security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's private reporting instead: open the repository's **Security** tab
and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the impact.

You can expect an acknowledgement, and a fix or a clear answer, as soon as the maintainer is able to look at it.
This is a personal open-source project, so there is no formal response-time guarantee.

## Scope

In scope: the API in `src/`, the Flutter app in `mobile/`, and the CI/CD workflows. Out of scope: any third-party
deployment of SpotOn you don't operate, and issues that need a rooted or compromised device.

## Never commit secrets

If you find a secret in the repository or its history, please report it privately in the same way.
